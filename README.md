# session-board

Claude Code 桌面版的對話儀表板 mod。在側邊面板監控你選的對話：標題、描述、狀態、最新動作、執行中的子代理；對話跑完時，會用一句話告訴你為什麼需要你。

## 狀態

| 狀態 | 意思 |
|---|---|
| 🙋 找你 | 這輪跑完，需要你決定、驗收或處理 |
| 💻 工作中 | 主對話正在做事 |
| 🎉 完成 | 跑完了，不用處理，或你已按「知道了」 |
| 💤 閒置 | 這個對話還沒有需要回報的結果 |
| 未連線 | 還沒收到回報，重開對話後才會回報 |

子代理不會改變卡片狀態。主對話在等你時，即使子代理還在跑，卡片仍是「找你」。

## 安裝

把這個資料夾的路徑加進 `~/.claude/settings.json`：

```json
{
  "env": {
    "CLAUDE_CODE_PLUGIN_DIRS": "/path/to/session-board"
  }
}
```

開新對話或重開舊對話後，按輸入框上方的「📋 儀表板」，或輸入 `/board`。

## 資料

各對話的回報和監控清單都存在本機的 `~/.claude/session-board/`。被監控的對話每輪結束時，會用 Haiku 把結果整理成一句話。

## 開發

```bash
claude plugin test .
```

```bash
claude plugin validate .
```

自動測試看不到桌面版的實際外觀，版面改動要在桌面版確認。顏色是為深色主題調的。
