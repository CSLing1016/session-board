# session-board

A Claude Code mod: a side-pane dashboard for the sessions you choose to watch. The interface is in Traditional Chinese.

Claude Code 的對話儀表板 mod，桌面版和 CLI 都能用。同時開很多對話時，不用一個一個切過去看，在側邊面板就能知道每個對話的狀態、正在做什麼，以及跑完後為什麼需要你。

## 安裝

需要 Claude Code。目前在 macOS 上的 v2.1.318 開發和測試。

```text
/plugin marketplace add CSLing1016/session-board
/plugin install session-board@session-board
```

已經開著的對話要重開，才會載入這個 mod 並開始回報。

## 卡片上有什麼

- 你替對話取的標題和描述
- 狀態和最新動作，例如「正在編輯 report.py」
- 跑完時的一句回報，語氣像員工跟老大報告，例如「週報弄好了，麻煩你驗收一下。」
- 執行中的子代理和它們的最新動作，最多列 3 個
- 最後更新時間，邊框顏色也會隨狀態改變
- 「開啟對話」和「知道了」按鈕

| 狀態 | 意思 |
|---|---|
| 🙋 找你 | 對話正在問你問題，或這輪跑完或被打斷，需要你決定、驗收或排除問題 |
| 🔌 中斷 | 顯示工作中的對話超過 2 分鐘沒有回應，可能當機或被強制結束 |
| 💻 工作中 | 主對話正在做事 |
| 🎉 完成 | 跑完了不用處理，或你已按「知道了」 |
| 💤 閒置 | 目前沒有要回報的結果 |
| 未連線 | 還沒收到回報，對話要裝了這個 mod 並重開後才會回報 |

子代理不會改變卡片狀態：主對話在等你時，即使子代理還在跑，卡片仍是「找你」。

## 使用

1. 按輸入框上方的「📋 儀表板」，或輸入 `/board`，打開側邊面板。
2. 面板最上方是當前對話：按「直接新增」馬上加入，或按「編輯並新增」先改標題和描述。要監控其他對話，按 ☰ →「新增」。
3. 之後狀態會自動更新。按「開啟對話」回到那個對話，按「知道了」清掉「找你」。
4. 按卡片左上角的 📌 把對話放進「置頂對話」，再按一次取消。
5. 「其他對話」依狀態分組，按狀態那一列可以展開或收合。預設展開找你、中斷、工作中。

每個對話都要裝這個 mod 才會回報。桌面版和 CLI 共用同一份監控清單。

### 「開啟對話」會做什麼

| 對話 | 結果 |
|---|---|
| 桌面版對話 | 跳到桌面 app 的那個對話 |
| CLI 對話還開著，在 Terminal 或 iTerm2 | 跳到那個視窗（第一次 macOS 會詢問是否允許控制該程式） |
| CLI 對話還開著，在其他終端機 | 無法自動跳轉，提示你自己切過去 |
| CLI 對話已關閉 | 開新終端機視窗，到原資料夾恢復對話 |

## 資料和費用

- 回報和監控清單存在本機的 `~/.claude/session-board/`，這個 mod 不會把它們傳到其他地方。
- **被監控的對話每輪結束時，會把最後約 3000 字送給 Haiku 模型寫那句回報，會用到你的 Claude 額度。**沒被監控的對話只記錄狀態，不呼叫模型。
- 在 CLI 列出可監控的對話時，會讀 `~/.claude/projects/` 裡的對話紀錄（只取標題和資料夾），以及桌面 app 在本機的對話紀錄檔。

## 已知限制

- 目前只考慮 macOS：終端機跳轉用 AppleScript，桌面版對話清單的路徑也是 macOS 專用。
- 終端機跳轉和恢復只在 Terminal 實際用過，iTerm2 的部分還沒驗證。
- 在 CLI 列出桌面版對話時，讀的是桌面 app 未公開的紀錄格式，app 更新後可能列不出來。
- 顏色是為深色主題調的，淺色主題可能不好看。
- 對話被強制結束或當機時，卡片要約 2 分鐘才會變成「中斷」。電腦睡眠剛醒來也可能短暫顯示「中斷」，對話還活著的話會自己恢復。
- 還跑著舊版 mod 的對話沒有心跳，不會變成「中斷」，要重開後才會偵測。
- 對話停在權限確認時仍顯示「工作中」。
- 介面和回報都是繁體中文，「老大」的稱呼目前不能設定。

## 開發

```bash
git clone https://github.com/CSLing1016/session-board.git
```

```bash
claude plugin test .
```

```bash
claude plugin validate .
```

自動測試看不到實際畫面，版面的改動要在桌面版和 CLI 上實際確認。
